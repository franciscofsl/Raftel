Classes

RaftelCorsOptions

Explicit CORS policy. No origin is allowed by default: an empty AllowedOrigins disables CORS.

RaftelForwardedHeadersOptions

Reverse proxies trusted to set X-Forwarded-For and X-Forwarded-Proto.

RaftelRateLimitOptions

Limits for the three named policies in RaftelRateLimitPolicies.

RaftelRateLimitPolicies

Names of the rate limiting policies registered by AddRaftelSecurity.

RaftelSecurityApplicationBuilderExtensions

Pipeline half of AddRaftelSecurity(IServiceCollection, IConfiguration, Action<RaftelSecurityOptions>). The order is:

app.UseCorrelationId();
app.UseRaftelExceptionHandling();
app.UseRaftelSecurity();        // forwarded headers, security headers, CORS
app.UseHttpsRedirection();
app.UseRouting();
app.UseAuthentication();
app.UseTenantMiddleware();
app.UseRaftelRateLimiting();    // after authentication and tenant resolution
app.UseAuthorization();
RaftelSecurityOptions

Rate limiting, CORS, security headers and forwarded headers settings applied by AddRaftelSecurity(IServiceCollection, IConfiguration, Action<RaftelSecurityOptions>).
