Namespace
Raftel.Application.Middlewares

Raftel.Application.dll

Global middleware that enriches the current request's IRequestEvent with the request name and outcome. It never logs directly — a single component further out in the pipeline emits the request's wide event exactly once — and never includes request property values, so credentials or other sensitive request payloads never reach a log sink.

HandleAsync(TRequest, RequestHandlerDelegate<TResponse>, CancellationToken)

Enriches the request event with the request name, then invokes the next delegate in the pipeline. On a failed Result, adds the error code/message and sets the event's level to Warning. On a thrown exception, adds the exception, sets the level to Error, and rethrows.
